04 · GitHub-Actions-Independent Pipeline

Built because ACT-009 has no owner-accessible fix

The org-level Actions policy blocker has been open for weeks with no path for the owner to reach the relevant Settings page. Rather than wait on it, the estate runs its own cadence: plain Python, real git, real local build/test/lint, fired by a scheduled Routine — zero GitHub Actions dependency for the decision layer.

01

conflict_resolver.py

Syncs feature branches against main. Real conflicts are flagged for judgment — never blind-resolved.

02

estate_ci.py

Runs each repo's actual local build/test/lint and writes a real status file, not a claimed one.

03

dependable_bot.py

OSV.dev + GitHub Advisory queries against each repo's real lock file.

04

estate_merge.py

Decides ready_to_merge vs skipped. The actual merge click is a separate, human-present step — GitHub's own API reserves it.

05

ip_forensics_scan.py

GitHub, Docker Hub, Hugging Face, npm, PyPI, crates.io, RubyGems, NuGet — against live infrastructure.

06

simcity_extended_pipeline.py

Canary probe, marketing engine, web generator every cycle; skill improver proposals Sundays only.

07

roadmaps_data_compilation.py

Feeds the business plan's product catalog from real CI output. Daily for a week, then every 72h, plus Sundays.

08

business_plan_pipeline.py

Ingest → classify → merge → validate → archive. Publish is a separate, human-approved step it can never reach on its own.
